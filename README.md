# Vairavel Accessories 💎

A modern ecommerce website for fashion accessories built using HTML, CSS, and JavaScript.

## 🚀 Features
- Product listing with categories
- Add to Cart with quantity (+ / -)
- Wishlist system
- Product detail page
- Dynamic product rendering using JavaScript
- Fully responsive design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🌐 Live Website
https://anusri-dev.github.io/vairavel-accessories/

Built as part of a 30 Days Challenge to improve frontend development skills.
